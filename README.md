# Software module for the processing of the EIS 
fl_eis_glpm is a software module, which allows to generate or to perform linear processing of the EIS 

Documentation will be provided separately for all EIS suit.

fl\_eis\_ecfm requires relatively fresh C++ compiler. 
Module can be built using **CodeBlocks IDE**  and **MinGW** compiler. fl\_eis\_tdim requires:
 **fmtlib** <https://github.com/fmtlib>
 **scnlib** <https://github.com/eliaskosunen/scnlib>
 **libconfig 1.7.3** from here: <https://github.com/nenin-sc/libconfig1.73alt> Priscine libconfig will require minor code corretion.
 **FLTK Generic Form Context** <https://github.com/nenin-sc/FLTK-Generic-Form-Context>
 **fltk_plotXY3** <https://github.com/nenin-sc/fltk_plotXY3>
 **SimpleXlsxWriter**  <https://sourceforge.net/projects/simplexlsx/> to make reports
 **fltk\_small\_stuff** <https://github.com/nenin-sc/fltk_small_stuff>
 **eis\_lib\_tree** <https://github.com/nenin-sc/eis_lib_tree>
 **eis\_lib\_shy**  <https://github.com/nenin-sc/eis_lib_shy>
It was not tested out of Windows, so potentially some issues may occure.
